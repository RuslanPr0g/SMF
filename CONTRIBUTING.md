# Contributing

Thanks for your interest in contributing!

## Workflow

1. Fork or branch from `main`.
2. Make your changes on a feature branch (e.g. `feature/your-change`).
3. Open a pull request into `main`.
4. At least **1 approving review** is required before merge.
5. Direct pushes and force pushes to `main` are disabled — all changes must go through a PR.

## CI Checks

On every PR: formatting check + type check/build (`ci.yml`). On push to `main`: auto-deploy to GitHub Pages (`deploy.yml`). Make sure formatting and build pass locally before opening a PR.
